3B3TPE // Technical Information

Server
Modifications

The following modifications and configuration changes are currently part of the 3B3TPE server. These changes are intended to preserve the server's anarchy environment while preventing certain mechanics from being abused to compromise the world or other players.

Current Modifications

01 / CONFIGURATION
01
World Generation

The world uses a modified vanilla terrain generator. This modification is intended to prevent players from generating their own copy of the world and using terrain-generation tools to reproduce the server's terrain outside of the server.

The terrain remains based on vanilla Minecraft generation, but the generation process has been modified to make reproducing the server world externally more difficult.
02
Phantoms

Phantoms do not spawn on the server. The doInsomnia gamerule is set to false, preventing phantom spawning caused by players not sleeping.

03
Player Spawning

Players spawn within a distance of 512 blocks from the 0, 0 center of the world. The spawning mechanic has also been changed to provide greater variety in the locations where players can spawn.

The spawn system does not simply place every player at the same location. Spawn locations are selected within the configured area to provide a more varied starting position.
04
Anticheat

Players are allowed to use cheats and modifications on the server. However, the server may prevent certain cheats or modifications from functioning at full capability. This is primarily intended to prevent harmful movement cheats and modifications that could negatively affect gameplay or server stability.

The server is not intended to prohibit modifications as a whole. Restrictions primarily exist where a modification can provide harmful movement capabilities or otherwise interfere with the server.
05
Nether Roof and Void

Access to the Nether roof and the world void has been blocked. Players cannot use normal gameplay mechanics or exploits to access these areas.

06
Chat

The server chat system includes several additional features and modifications beyond the standard Minecraft chat system.

Detailed information about the chat modifications can be found here .

07
Ender Pearls

Thrown ender pearls do not vanish when the player who threw them dies, provided the pearl remains within the relevant render range. This allows already-thrown pearls to continue existing after the thrower's death instead of immediately disappearing.

08
Locator Bar

The Locator Bar has been disabled. This prevents player locations from becoming publicly visible through the Locator Bar and keeps player positions from being automatically exposed to other players.

Players must rely on their own observations and information rather than receiving automatic location information through the Locator Bar.
