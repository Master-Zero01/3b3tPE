3B3TPE // Chat Reference

Commands

These are all the chat commands that are available.

Private messages
/msg [name]
/whisper [name]
/pm [name]
/w [name]
Send a private message to a player using any of these commands.
Replies
/r [message]
/reply [message]
Quickly reply to another player's private message.
Be aware that this sends your message to the player that last messaged you. You may accidentally send your message to the wrong player. If you want to be absolutely sure, instead use the following, which sends your message to the player that you last messaged.
Hiding specific player messages
/ignore [name]
This will ignore a player temporarily, and is cleared periodically.
/ignorelist
This will display a list of players you have ignored permanently. You can click on the button next to a player's name to unignore them.
Chat visibility
/togglechat
This will toggle the visibility of the default global chat.
/toggleprivatemsgs
This will toggle the visibility of private messages.
Miscellaneous
/kill
Instantly kills your player.
